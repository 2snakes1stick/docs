# Hero Section Component

The Hero Section is the primary visual component that welcomes visitors to the LÖTUS experience. It features either a dynamic 7-second promotional video or a stunning static image, designed to capture the essence of our exclusive wellness retreats.

## Overview

The hero section adapts based on available content and user preferences, providing either:
- **Video Hero**: 7-second promotional video showcasing helicopter arrivals, underwater footage, and wellness activities
- **Static Hero**: High-quality image with animated text overlays and logo presentation

## Component API

### Props

```typescript
interface HeroSectionProps {
  /** Enable video background (requires video assets) */
  enableVideo?: boolean;
  
  /** Video source URL or path */
  videoSrc?: string;
  
  /** Fallback image for static hero */
  imageSrc: string;
  
  /** Hero headline text */
  headline?: string;
  
  /** Logo configuration */
  logo?: {
    src: string;
    alt: string;
    width?: number;
    height?: number;
  };
  
  /** Call-to-action button */
  cta?: {
    text: string;
    href: string;
    variant?: 'primary' | 'secondary';
  };
  
  /** Accessibility and SEO */
  alt?: string;
  priority?: boolean;
}
```

### Default Props

```typescript
const defaultProps: Partial<HeroSectionProps> = {
```

## Video Specifications

### Technical Requirements

- **Duration**: 7 seconds exactly
- **Format**: MP4 (H.264 codec recommended)
- **Resolution**: 1920x1080 minimum, 4K preferred
- **Aspect Ratio**: 16:9
- **File Size**: < 5MB for optimal loading
- **Audio**: No audio track (muted autoplay)

### Content Guidelines

The 7-second video should include:

1. **Opening (0-2s)**: Helicopter arrival or dramatic entrance
2. **Middle (2-4s)**: Underwater barracuda footage or nature shots
3. **Wellness (4-6s)**: Women practicing yoga/pilates in harmony
4. **Finale (6-7s)**: Freeze on final pose with logo overlay

## Accessibility Features

### WCAG 2.1 AA Compliance

- **Keyboard Navigation**: CTA button fully keyboard accessible
- **Screen Reader Support**: Proper ARIA labels and alt text
- **Reduced Motion**: Respects `prefers-reduced-motion` setting
- **Color Contrast**: Text overlay ensures 4.5:1 contrast ratio
- **Focus Indicators**: Clear focus states for interactive elements

## Testing

### Unit Tests

```typescript
import { render, screen } from '@testing-library/react';
import { HeroSection } from './hero-section';

describe('HeroSection', () => {
  it('renders headline correctly', () => {
    render(<HeroSection imageSrc="/test.jpg" />);
    expect(screen.getByRole('heading', { level: 1 }))
      .toHaveTextContent('YOUR EXCLUSIVE WELLNESS AND PILATES RETREAT');
  });
  
  it('displays video when enabled', () => {
    render(
      <HeroSection
        enableVideo={true}
        videoSrc="/test.mp4"
        imageSrc="/test.jpg"
      />
    );
    expect(screen.getByRole('banner')).toContainElement(
      screen.getByTestId('hero-video')
    );
  });
  
  it('fallback to image when video fails', async () => {
    render(
      <HeroSection
        enableVideo={true}
        videoSrc="/invalid.mp4"
        imageSrc="/test.jpg"
      />
    );
    
    // Simulate video error
    const video = screen.getByTestId('hero-video');
    fireEvent.error(video);
    
    await waitFor(() => {
      expect(screen.getByAltText(/pilates retreat/i)).toBeInTheDocument();
    });
  });
});
```

## Best Practices

### Content Guidelines

1. **Visual Consistency**: Maintain brand colors and typography
2. **Message Clarity**: Keep headline concise and impactful
3. **Loading Priority**: Hero content loads before other page elements
4. **Mobile Experience**: Ensure readability on all screen sizes

### Technical Guidelines

1. **Performance**: Optimize assets for fast loading
2. **Accessibility**: Test with screen readers and keyboard navigation
3. **Fallbacks**: Always provide image fallback for video
4. **Testing**: Test across different browsers and devices
