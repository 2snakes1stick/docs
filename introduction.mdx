## Technical Architecture

The LÖTUS platform is built with modern web technologies focusing on:

- **Performance**: Fast loading times and smooth interactions

- **Mobile-First**: Responsive design optimized for all devices

## Quick Start

<Steps>
  <Step title="Environment Setup">
    Clone the repository and install dependencies
    ```bash
    git clone https://github.com/lotus-retreats/website
    cd website
    npm install
    ```
  </Step>
  <Step title="Configuration">
    Set up your environment variables and API keys
    ```bash
    cp .env.example .env.local
    # Edit .env.local with your configuration
    ```
  </Step>
  <Step title="Development">
    Start the development server
    ```bash
    npm run dev
    ```
  </Step>
  <Step title="Deployment">
    Build and deploy to your preferred platform
    ```bash
    npm run build
    npm run deploy
    ```
  </Step>
</Steps>
