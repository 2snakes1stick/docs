# Development Setup

This guide will help you set up a complete development environment for the LÖTUS platform, including frontend, backend, and all necessary dependencies.

## System Requirements

### Minimum Requirements

<AccordionGroup>
  <Accordion title="Hardware">
    - **RAM**: 8GB minimum, 16GB recommended
    - **Storage**: 20GB free space
    - **CPU**: Intel i5 or AMD Ryzen 5 equivalent
    - **Internet**: Stable broadband connection
  </Accordion>
  
  <Accordion title="Operating System">
    - **macOS**: 10.15 (Catalina) or later
    - **Windows**: Windows 10 or later with WSL2
    - **Linux**: Ubuntu 18.04+ or equivalent
  </Accordion>
</AccordionGroup>

### Required Software

<CardGroup cols={2}>
  <Card title="Node.js" icon="js">
    Version 18.0 or higher for frontend development
  </Card>
  <Card title="Docker" icon="docker">
    For containerized development environment

## Quick Start

Get up and running in under 10 minutes:

<Steps>
  <Step title="Clone Repository">
    ```bash
    git clone https://github.com/lotus-retreats/platform.git
    cd platform
    ```
  </Step>
  
  <Step title="Install Dependencies">
    ```bash
    npm install
    ```
  </Step>
  
  <Step title="Setup Environment">
    ```bash
    cp .env.example .env.local
    # Edit .env.local with your configuration
    ```
  </Step>
  
  <Step title="Start Development">
    ```bash
    npm run dev
    ```
  </Step>
</Steps>

### 2. Project Setup

#### Clone and Install

```bash
# Clone the repository
git clone https://github.com/lotus-retreats/platform.git
cd platform

# Install dependencies
npm install

# Install global tools
npm install -g @lotus-retreats/cli
npm install -g prisma
npm install -g pm2
```

#### Environment Configuration

Create your environment file:

```bash
cp .env.example .env.local
```

Configure your environment variables:

<CodeGroup>

### 3. Database Setup

#### Using Docker (Recommended)

```bash
# Start PostgreSQL and Redis
docker-compose up -d postgres redis

# Verify containers are running
docker ps
```

#### Manual Installation

<Tabs>
  <Tab title="PostgreSQL">
    ```bash
    # macOS
    brew install postgresql@14
    brew services start postgresql@14
    
    # Create database and user
    createdb lotus_dev
    createuser -s lotus
    psql -d lotus_dev -c "ALTER USER lotus PASSWORD 'password';"
    ```
  </Tab>
  
  <Tab title="Redis">
    ```bash
    # macOS
    brew install redis
    brew services start redis
    
    # Linux
    sudo apt install redis-server
    sudo systemctl start redis-server
    ```
  </Tab>
</Tabs>

#### Database Migration

```bash
# Generate Prisma client
npx prisma generate

# Run migrations
npx prisma migrate dev

# Seed database with sample data
npx prisma db seed
```

## Docker Development

### Docker Compose Setup

```yaml
# docker-compose.dev.yml
version: '3.8'

services:
  postgres:
    image: postgres:14
    environment:
      POSTGRES_DB: lotus_dev
      POSTGRES_USER: lotus
      POSTGRES_PASSWORD: password
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data

  minio:
    image: minio/minio
    environment:
      MINIO_ROOT_USER: minioadmin
      MINIO_ROOT_PASSWORD: minioadmin
    ports:
      - "9000:9000"
      - "9001:9001"
    volumes:
      - minio_data:/data
    command: server /data --console-address ":9001"

volumes:
  postgres_data:
  redis_data:
  minio_data:
```

### Development Container

For a fully containerized development environment:

```dockerfile
# .devcontainer/Dockerfile
FROM node:18

# Install additional tools
RUN apt-get update && apt-get install -y \
    git \
    curl \
    vim \
    postgresql-client \
    && rm -rf /var/lib/apt/lists/*

# Install global npm packages
RUN npm install -g @lotus-retreats/cli prisma pm2

WORKDIR /workspace

# Install dependencies
COPY package*.json ./
RUN npm ci

EXPOSE 3000 3001 5555
```

## Troubleshooting

### Common Issues

<AccordionGroup>
  <Accordion title="Port Already in Use">
    ```bash
    # Find process using port
    lsof -ti:3000
    
    # Kill process
    kill -9 $(lsof -ti:3000)
    
    # Or use different port
    PORT=3002 npm run dev
    ```
  </Accordion>
  
  <Accordion title="Database Connection Failed">
    ```bash
    # Check if PostgreSQL is running
    docker ps | grep postgres
    
    # Restart database
    docker-compose restart postgres
    
    # Test connection
    npx prisma db push
    ```
  </Accordion>
  
  <Accordion title="Module Not Found">
    ```bash
    # Clear dependencies
    rm -rf node_modules package-lock.json
    npm install
    
    # Clear Next.js cache
    rm -rf .next
    
    # Restart TypeScript server in VSCode
    ```
  </Accordion>
  
  <Accordion title="Permission Denied (Docker)">
    ```bash
    # Linux: Add user to docker group
    sudo usermod -aG docker $USER
    newgrp docker
    
    # macOS: Restart Docker Desktop
    ```
  </Accordion>
</AccordionGroup>
