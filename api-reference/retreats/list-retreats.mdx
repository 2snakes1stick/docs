# List Retreats

Retrieves a paginated list of retreats with comprehensive filtering, search, and sorting options. This endpoint provides all the information needed to display retreat listings and availability.

## Endpoint

```http
GET /api/v1/retreats
```

## Authentication

This endpoint can be accessed without authentication for basic retreat information. Authentication is required for detailed availability and pricing information.

```http
Authorization: Bearer YOUR_JWT_TOKEN
```

## Query Parameters

### Pagination

<ParamField query="page" type="integer" default="1">
  Page number to retrieve (starting from 1)
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Number of retreats per page (maximum 100)
</ParamField>

### Sorting

<ParamField query="sort" type="string" default="start_date">
  Field to sort by. Options: `start_date`, `price`, `title`, `created_at`, `popularity`
</ParamField>

<ParamField query="order" type="string" default="asc">
  Sort order: `asc` (ascending) or `desc` (descending)
</ParamField>

### Filtering

<ParamField query="status" type="string">
  Filter by retreat status: `available`, `limited`, `sold_out`, `upcoming`, `completed`
</ParamField>

<ParamField query="location" type="string">
  Filter by country or region (e.g., "brazil", "costa-rica")
</ParamField>

<ParamField query="city" type="string">
  Filter by specific city (e.g., "itacare", "tulum")
</ParamField>

<ParamField query="start_date_from" type="string">
  Filter retreats starting from this date (YYYY-MM-DD format)
</ParamField>

<ParamField query="start_date_to" type="string">
  Filter retreats starting before this date (YYYY-MM-DD format)
</ParamField>

<ParamField query="min_price" type="number">
  Minimum price filter (in USD)
</ParamField>

<ParamField query="max_price" type="number">
  Maximum price filter (in USD)
</ParamField>

<ParamField query="duration_days" type="integer">
  Filter by retreat duration in days
</ParamField>

<ParamField query="difficulty_level" type="string">
  Filter by difficulty: `beginner`, `intermediate`, `advanced`, `all_levels`
</ParamField>

<ParamField query="amenities" type="string">
  Comma-separated list of required amenities (e.g., "spa,beach_access,airport_transfer")
</ParamField>

### Search

<ParamField query="search" type="string">
  Search query for retreat titles, descriptions, and locations
</ParamField>

<ParamField query="featured" type="boolean">
  Filter to show only featured retreats
</ParamField>

## Filtering Examples

### Date Range Filtering

```bash
# Retreats in March 2024
curl "https://api.lotus-retreats.com/v1/retreats?start_date_from=2024-03-01&start_date_to=2024-03-31"

# Retreats starting within the next 6 months
curl "https://api.lotus-retreats.com/v1/retreats?start_date_from=$(date +%Y-%m-%d)&start_date_to=$(date -d '+6 months' +%Y-%m-%d)"
```

### Price Range Filtering

```bash
# Budget-friendly retreats under $2000
curl "https://api.lotus-retreats.com/v1/retreats?max_price=2000&sort=price&order=asc"

# Luxury retreats over $5000
curl "https://api.lotus-retreats.com/v1/retreats?min_price=5000&sort=price&order=desc"
```

### Location and Amenity Filtering

```bash
# Beach retreats in Brazil with spa facilities
curl "https://api.lotus-retreats.com/v1/retreats?location=brazil&amenities=beach_access,spa"

# All-levels retreats with airport transfers
curl "https://api.lotus-retreats.com/v1/retreats?difficulty_level=all_levels&amenities=airport_transfer"
```

## Search Functionality

The search parameter supports:

- **Title matching**: Partial and full title matches
- **Description search**: Keyword matching in descriptions
- **Location search**: City, state, and country names
- **Instructor search**: Instructor names and specialties
- **Amenity search**: Facility and service names

### Search Examples

```bash
# Search for coastal retreats
curl "https://api.lotus-retreats.com/v1/retreats?search=coastal"

# Search for specific instructor
curl "https://api.lotus-retreats.com/v1/retreats?search=maria+santos"

# Combined search and filters
curl "https://api.lotus-retreats.com/v1/retreats?search=pilates&location=brazil&status=available"
```

## Sorting Options

Available sorting fields:

| Sort Field | Description |
|------------|-------------|
| `start_date` | Retreat start date (default) |
| `price` | Base price |
| `title` | Alphabetical by title |
| `created_at` | When retreat was created |
| `popularity` | Based on bookings and reviews |
| `rating` | Average review rating |
| `availability` | Available spots (descending) |

## SDK Examples

### JavaScript/React Integration

```javascript
import { LotusAPI } from '@lotus-retreats/sdk';
import { useState, useEffect } from 'react';

const RetreatListing = () => {
  const [retreats, setRetreats] = useState([]);
  const [loading, setLoading] = useState(true);
  const [filters, setFilters] = useState({
    status: 'available',
    location: '',
    sort: 'start_date',
    order: 'asc'
  });

  const lotus = new LotusAPI({ apiKey: process.env.NEXT_PUBLIC_LOTUS_API_KEY });

  useEffect(() => {
    const fetchRetreats = async () => {
      setLoading(true);
      try {
        const response = await lotus.retreats.list(filters);
        setRetreats(response.data);
      } catch (error) {
        console.error('Failed to fetch retreats:', error);
      } finally {
        setLoading(false);
      }
    };

    fetchRetreats();
  }, [filters]);

  const handleFilterChange = (newFilters) => {
    setFilters({ ...filters, ...newFilters });
  };

  if (loading) return <div>Loading retreats...</div>;

  return (
    <div>
      {retreats.map(retreat => (
        <div key={retreat.id} className="retreat-card">
          <h3>{retreat.title}</h3>
          <p>{retreat.location.city}, {retreat.location.country}</p>
          <p>From ${retreat.pricing.base_price}</p>
          <p>{retreat.capacity.available_spots} spots available</p>
        </div>
      ))}
    </div>
  );
};
```

### Python Integration

```python
import lotus_retreats
from datetime import datetime, timedelta

client = lotus_retreats.Client(api_key='your_api_key')

# Get available retreats in the next 3 months
next_3_months = datetime.now() + timedelta(days=90)

retreats = client.retreats.list(
    status='available',
    start_date_from=datetime.now().strftime('%Y-%m-%d'),
    start_date_to=next_3_months.strftime('%Y-%m-%d'),
    sort='price',
    order='asc',
    limit=50
)

for retreat in retreats.data:
    print(f"{retreat.title} - ${retreat.pricing.base_price}")
    print(f"  Location: {retreat.location.city}, {retreat.location.country}")
    print(f"  Dates: {retreat.dates.start_date} to {retreat.dates.end_date}")
    print(f"  Available: {retreat.capacity.available_spots} spots")
    print()
```

## Performance Considerations

### Caching

- Retreat listings are cached for 5 minutes
- Individual retreat details are cached for 1 minute
- Availability information is cached for 30 seconds

### Optimization Tips

1. **Use pagination**: Don't request all retreats at once
2. **Apply filters**: Reduce dataset size with specific filters
3. **Limit fields**: Use field selection when available
4. **Cache results**: Cache retreat data on the client side appropriately

### Cache Headers

```http
Cache-Control: public, max-age=300
ETag: "retreat-list-hash-12345"
Last-Modified: Mon, 15 Jan 2024 14:20:00 GMT
```

## Real-time Updates

For real-time availability updates, consider using:

1. **Polling**: Refresh data every 30-60 seconds
2. **WebSockets**: Subscribe to retreat availability updates
3. **Webhooks**: Receive notifications for availability changes

### WebSocket Subscription

```javascript
const ws = new WebSocket('wss://api.lotus-retreats.com/v1/realtime');

ws.onopen = () => {
  ws.send(JSON.stringify({
    type: 'subscribe',
    channel: 'retreat_availability',
    retreat_ids: ['ret_itacare_brazil_2024', 'ret_tulum_mexico_2024']
  }));
};

ws.onmessage = (event) => {
  const update = JSON.parse(event.data);
  if (update.type === 'availability_changed') {
    updateRetreatAvailability(update.retreat_id, update.available_spots);
  }
};
```
