# Create Booking

Creates a new booking for a retreat. This endpoint handles the complete booking process including guest information validation, availability checking, and payment processing initiation.

## Endpoint

```http
POST /api/v1/bookings
```

## Authentication

This endpoint requires authentication. Include your JWT token in the Authorization header.

```http
Authorization: Bearer YOUR_JWT_TOKEN
```

## Request Body

### Required Fields

<ParamField body="retreat_id" type="string" required>
  The unique identifier of the retreat to book
</ParamField>

<ParamField body="guest_info" type="object" required>
  Complete guest information object
  
  <Expandable title="Guest Info Properties">

    </ParamField>
    
    <ParamField body="guest_info.last_name" type="string" required>

    </ParamField>
    
    <ParamField body="guest_info.email" type="string" required>

    </ParamField>
    
    <ParamField body="guest_info.phone" type="string" required>

    <ParamField body="guest_info.date_of_birth" type="string" required>
      Date of birth in YYYY-MM-DD format (must be 18+ years old)
    </ParamField>
    
    <ParamField body="guest_info.emergency_contact" type="object" required>
      Emergency contact information
      
      <ParamField body="guest_info.emergency_contact.name" type="string" required>
        Emergency contact full name
      </ParamField>
      
      <ParamField body="guest_info.emergency_contact.phone" type="string" required>
        Emergency contact phone number
      </ParamField>
      
      <ParamField body="guest_info.emergency_contact.relationship" type="string" required>
        Relationship to guest (e.g., "spouse", "parent", "friend")
      </ParamField>
    </ParamField>
  </Expandable>
</ParamField>

</ParamField>

<ParamField body="guest_info.special_requests" type="string">

<ParamField body="promo_code" type="string">
  Promotional code for discounts
</ParamField>

<ParamField body="preferred_room_type" type="string">
  Preferred accommodation type if available
</ParamField>

## Booking Process Flow

<Steps>
  <Step title="Submit Booking Request">
    Send POST request with guest information and retreat ID
  </Step>
  
  <Step title="Validation & Availability Check">
    System validates data and checks retreat availability in real-time
  </Step>
  
  <Step title="Booking Creation">
    If valid and available, booking is created with "pending_payment" status
  </Step>
  
  <Step title="Payment Processing">
    Guest redirected to secure payment URL to complete transaction
  </Step>
  
  <Step title="Confirmation">
    Upon successful payment, booking status changes to "confirmed"
  </Step>
</Steps>

## Business Logic

### Age Validation

- All guests must be at least 18 years old
- Date of birth is validated against current date
- Age calculation considers leap years

### Availability Checking

- Real-time availability is checked before booking creation
- Bookings are held for 30 minutes to allow payment completion
- Concurrent booking attempts are handled with proper locking

### Pricing Calculation

- Base price is retrieved from retreat configuration
- Promotional codes are applied if valid and not expired
- Additional guest fees are calculated automatically
- All pricing includes applicable taxes

### Booking Expiration

- Unpaid bookings expire after 30 minutes
- Expired bookings automatically release held spots
- Email reminders are sent 15 minutes before expiration

## Integration Examples

### JavaScript/React

```javascript
import { LotusAPI } from '@lotus-retreats/sdk';

const createBooking = async (bookingData) => {
  try {
    const booking = await LotusAPI.bookings.create(bookingData);
    
    // Redirect to payment
    window.location.href = booking.payment.payment_url;
    
    return booking;
  } catch (error) {
    if (error.code === 'RETREAT_UNAVAILABLE') {
      // Show alternative dates
      showAlternativeDates(error.details.next_available_dates);
    } else {
      // Handle other errors
      showErrorMessage(error.message);
    }
  }
};
```

### Python

```python
import lotus_retreats

client = lotus_retreats.Client(api_key='your_api_key')

try:
    booking = client.bookings.create({
        'retreat_id': 'ret_itacare_brazil_2024',
        'guest_info': {
            'first_name': 'Sarah',
            'last_name': 'Johnson',
            'email': 'sarah@example.com',
            # ... other fields
        }
    })
    
    print(f"Booking created: {booking.confirmation_code}")
    
except lotus_retreats.ValidationError as e:
    print(f"Validation error: {e.details}")
    
except lotus_retreats.RetreatUnavailableError as e:
    print(f"Retreat unavailable: {e.reason}")
```

## Webhooks

When a booking is created, the following webhook events are triggered:

- `booking.created` - Immediately after booking creation
- `booking.payment_pending` - When payment is required
- `booking.confirmed` - When payment is successfully processed
- `booking.expired` - If booking expires without payment

## Rate Limiting

This endpoint has specific rate limits:

- **Authenticated users**: 10 booking attempts per hour
- **Anonymous users**: 3 booking attempts per hour per IP
- **Burst limit**: 3 requests per minute

Rate limit headers:
```http
X-RateLimit-Limit: 10
X-RateLimit-Remaining: 9
X-RateLimit-Reset: 1705324200
```
